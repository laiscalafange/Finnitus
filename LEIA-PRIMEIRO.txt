FINNITUS — PACOTE LGPD PARA TESTES (APP + BACK-END)
====================================================

Este ZIP contém APENAS arquivos do aplicativo e da API, incluindo as páginas jurídicas nativas e o teste de isolamento. NÃO inclui o site nem arquivos .env, node_modules, bancos, imagens ou credenciais.

IMPORTANTE: No seu git status, os arquivos de correção JÁ aparecem como modified / untracked. Isso é compatível com as correções JÁ terem sido copiadas. NÃO os substitua novamente só porque o Git diz "modified".

ORDEM MAIS SEGURA
----------------
1. Mantenha a branch 'lgpd' atual. NÃO execute `git restore .` ou `git clean -fd`.
2. Extraia este ZIP em uma pasta SEPARADA, fora do repositório.
3. A partir da RAIZ DO PROJETO, execute este comando PowerShell (copiando o caminho correto para a pasta extraída):

   powershell -ExecutionPolicy Bypass -File "C:\CAMINHO\DO\ZIP_EXTRAIDO\VERIFICAR-INSTALACAO.ps1" -ProjectRoot .

   O script apenas COMPARA o pacote com os arquivos locais. Ele NÃO altera o seu código.

4. Se os arquivos já estiverem iguais, pule a cópia e siga para os testes.
5. Se houver diferenças, compare pelo VS Code antes de substituir. Algumas diferenças são alterações da equipe feitas DEPOIS do pacote da auditoria, especialmente PlanoB e calendário.
6. O ajuste incluído nesta versão altera o registro da tela legal no `src/app/_layout.jsx` de `name="legal"` para `name="legal/[doc]"`. Caso queira aplicar APENAS este ajuste, faça essa troca manual em seu arquivo atual.

TESTES INICIAIS (SEM ALTERAR ARQUIVOS)
-------------------------------------
Execute na RAIZ DO PROJETO:
  npx tsc --noEmit
  npx expo start -c

Para a API:
  cd src/backend
  npm run typecheck
  npm run dev

Se `npm run typecheck` não existir, tente `npx tsc --noEmit`.

Teste no app: criar conta, login, Google, abrir políticas sem login, abrir políticas depois do login, Planos sem cartão, logout, Plano B e calendário.

TESTE DE ISOLAMENTO — ATENÇÃO
---------------------------
O teste `src/backend/tests/isolamento.api.test.mjs` CRIA usuários e dados e TENTA excluí-los ao final. USE EXCLUSIVAMENTE BANCO DESCARTÁVEL, em ambiente local isolado. Configurar `AUDIT_TEST_URL=localhost` NÃO garante que o banco é local: confira DATABASE_URL no ambiente do servidor!

Com o servidor local apontando para BANCO DE TESTE, no PowerShell:
  cd src/backend
  $env:AUDIT_TEST_URL = "http://127.0.0.1:3333"
  node --test tests/isolamento.api.test.mjs

Testes automatizados com banco real, integração com Render/Neon, permissões de produção e revisão jurídica final ainda NÃO foram executados aqui. "Passou TypeScript" não significa que o app foi testado por completo.
